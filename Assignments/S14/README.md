# Session 14: Turning a linear model into an MoE

## Project

Train a linear model, convert it into a mixture-of-experts (MoE) model, and demonstrate that training continues after the conversion while held-out loss decreases.

## Experiment

- Task: deterministic scalar regression on a piecewise-linear function with three input regions.
- Baseline: one `Linear(1, 1)` model trained on 2,048 generated training examples.
- Conversion: copy the trained linear weights and bias into three experts, add a small deterministic symmetry-breaking offset, and initialize a linear softmax router to favor the three input regions. Before the offsets are applied, the identical expert copies reproduce the baseline predictions exactly; the code checks this function-preserving conversion numerically.
- Continued training: train the converted three-expert model on the same training examples and compare train and held-out MSE.
- Evidence: [experiment notebook](./session14.ipynb), [training script](./session14_moe.py), [results](./output/session14_results.json), [fit and routing plot](./output/linear_to_moe.png), [training-loss plot](./output/session14_training_loss.png), and [loss history](./output/session14_loss_history.csv).

The symmetry-breaking offsets allow initially identical experts to learn different functions. The controlled synthetic task is a proof of the conversion and continued-training workflow, not a benchmark of MoE scaling or real-world generalization.

## Results

The experiment completed locally on CPU (macOS, PyTorch 2.14.1; one CPU thread). The 2-parameter linear model trained for 500 steps, then its three-expert, 12-parameter MoE conversion trained for 1,500 more steps on the same training set.

| Measurement | Linear baseline / at conversion | MoE after continued training |
| --- | ---: | ---: |
| Training MSE | 0.194415 | 0.001195 |
| Held-out validation MSE | 0.185814 | 0.001232 |

The converted experts reproduced the baseline predictions with maximum absolute error `1.19e-7` before the small symmetry-breaking offsets. After conversion and further training, held-out MSE decreased by **99.34%**. The slight offset itself changed validation MSE to `0.184215` before training; the report records this separately in the JSON results.
